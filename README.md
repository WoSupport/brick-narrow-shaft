# The Narrow Shaft

A Breakout-style paddle game with a specific level-design challenge:

- A **fortress of unbreakable steel** spans the screen.
- The only way in is a **narrow breakable door** in the steel roof.
- You must thread the ball through the door into the **prize chamber** — hard to do, once you're in, the ball opens up space and **auto-plays**.
- Grab **⚡ split** pickups for **multiball chain reactions** that clear the rest.

Playable at:
https://wosupport.github.io/brick-narrow-shaft/

## Controls
- **Move paddle:** mouse / Arrow keys (←/→ or A/D) / touch
- **Launch / advance:** click or Space

## Files
- `index.html` — the entire game (vanilla HTML5 Canvas, no dependencies)
- `docs/` — the deployable copy served by GitHub Pages
- `verify/` — headless Chromium (Puppeteer) verification script
